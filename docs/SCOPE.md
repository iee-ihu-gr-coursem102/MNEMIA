# MNEMIA - Scope & MVP Definition

## Minimum Viable Product (MVP) - Sprint 1
Για την πρώτη λειτουργική έκδοση της εφαρμογής, δεσμευόμαστε να παραδώσουμε **μόνο** τις παρακάτω λειτουργίες:
1. Αναζήτηση & Εμφάνιση: Ο χρήστης μπορεί να αναζητήσει πολιτιστικά αντικείμενα μέσω keyword (σύνδεση με Europeana API).
2. Λίστα Αποτελεσμάτων: Βασικό UI που εμφανίζει τον τίτλο, την εικόνα και τον δημιουργό του αντικειμένου.
3. Βάση Δεδομένων: Στήσιμο πινάκων για Users και Collections, ώστε να είναι έτοιμα για το επόμενο στάδιο.

##  Out of Scope (Δεν θα αναπτυχθούν στο Sprint 1)
Τα παρακάτω features είναι σημαντικά, αλλά μεταφέρονται για το Sprint 2+ ώστε να διασφαλίσουμε την ποιότητα του πυρήνα της εφαρμογής:
- Σύστημα Login / Εγγραφής χρηστών (Authentication).
- Δημιουργία και διαχείριση Προσωπικών Συλλογών.
- Κουίζ, Πόντοι και Gamification.
- Κοινωνικές λειτουργίες (Σχόλια, Ακολουθία άλλων χρηστών).
- Χάρτης πολιτιστικών σημείων.
