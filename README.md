## Εγκατάσταση και Εκτέλεση (Τοπικό Περιβάλλον)
Για να τρέξετε το project τοπικά στον υπολογιστή σας:
1. `git clone https://github.com/AlexGkakios/MNEMIA.git`
2. `cd MNEMIA`
3. `python3 -m venv .venv`
4. `source .venv/bin/activate` (Για Windows: `.venv\Scripts\activate`)
5. `pip install -r requirements.txt`# MNEMIA
Development of a web application for utilizing cultural heritage data.
